# 한 문장 요약 품질 검토

현재 버전은 아래에서 검토한 자유 생성 방식을 사용하지 않습니다. AI는 원문 후보 번호만 선택하고 앱이 원문 문장을 표시합니다. 변경 후 출처 일치는 [검증 결과](source-selection-check.json)에서 확인할 수 있습니다. 아래 비교는 이전 방식의 실패 기록이며, 문장 선택의 대표성·원문 자체의 진실성은 여전히 별도 평가가 필요합니다.

현재 0.6B 모델의 의미 정확성은 제한적입니다. 실행 테스트 통과와 요약 품질은 별개이며, 복잡한 문서까지 품질이 확보되었다고 주장하지 않습니다.

## 수정한 입력 처리

기존에는 5개 섹션에서 위치만 보고 4개를 고르면서 핵심 결정을 생략할 수 있었습니다. 개최일과 후속 일정이 주요 결론보다 앞에 들어가 모델이 서로 다른 사건을 섞기도 했습니다.

이제 전체 임시 DB에서 주요 결정·결론을 위치 커버리지와 함께 찾습니다. 그 핵심 구간과 관련 보충 근거만 모델에 전달해 한 문장 압축을 요청합니다. 모든 섹션의 원문 근거는 임시 DB에 유지합니다. 모델에 내장된 대화 템플릿을 사용하고 한 문장·토큰 한도·수치·일부 시제·날짜 검사와 캐시 미사용을 유지합니다.

## 비교 방법

`scripts/compare_quality.py`는 한국어 4개와 영어 3개 합성 문서를 실제 문서 판별·추출·AI 워커로 처리합니다. Qwen3 0.6B Q4_K_M과 llama.cpp 프로젝트 배포의 Qwen3.5 0.8B Q4_0을 CPU 스레드 2개, 컨텍스트 2K, 합산 2GB 프로세스 트리 제한에서 비교합니다. 기본 모델은 0.6B로 유지했습니다.

키워드 점검은 주제 누락을 찾는 보조 지표이며 의미 정확도 점수가 아닙니다. 실제 문장·생성 초안·시간·메모리·fallback 여부는 [원본 결과](quality-comparison.json)에 남겼습니다. 벤치마크의 합성 문장 보관은 사용자 문서의 요약 캐시가 아닙니다.

## 수동 출력 검토

- 회의록: 개선 전의 개최일 또는 4GB 호환성 한 항목 대신, 0.6B가 “첫 번째 배포에서는 파일 탐색, 이름 검색 및 문서 미리보기를 우선 제공합니다.”라는 실제 결정을 요약했습니다. 본문 검색과 오프라인 발췌 방식을 모두 포함하지는 못했습니다.
- 운영 지표: 0.6B가 처리 건수 25% 증가와 검토 시간 감소를 함께 요약했지만 표현은 어색하고 구체적 시간은 생략했습니다. 0.8B가 근거에 없는 감소 시간을 계산한 출력은 거부됐습니다.
- 공유 금지: 0.6B가 자동 업로드 금지·사용자 승인·로컬 저장의 핵심을 유지했습니다. “로컬 저장소에 올린다”처럼 덜 명확한 표현이 남습니다.
- 스트리밍: 두 모델 모두 64KB 버퍼와 전체 텍스트를 보관하지 않는 구조를 다뤘습니다. 0.6B의 “작업 중입니다”는 원문의 설계 설명과 비교해 모호합니다.
- 영문 파일럿: 0.6B는 클라우드 이전 거절과 20명 로컬 파일럿 승인을 보존했습니다. 0.8B 문장은 운영 배포를 나중에 허용한다는 인상을 줄 수 있었습니다.
- 디스크 장애: 계속 사용할 수 있었던 탐색 기능을 “복구됐다”고 생성하는 사례가 있어 거부 규칙과 회귀 테스트를 추가했습니다. 대체 원문은 예방 조치에 치우쳐 장애 원인의 전체 설명으로는 부족합니다.
- 제품 PDF: 페이지 처리와 256MB 제한을 요약하지만 제품 전체의 주제는 좁게 잡습니다. 두 모델 모두 이 사례를 충분히 해결하지 못했습니다.

0.8B 후보는 일반적으로 약 717MiB의 모델 RSS와 더 긴 지연을 보였고, 한 실행에서는 약 813MiB의 순간 최대 RSS가 관측됐습니다. 기본값으로 채택하지 않았으며, RSS 감시도 현재 사용량뿐 아니라 관측된 최고 사용량을 검사하도록 수정했습니다. OS의 commit/주소공간 제한과 주기적 RSS 감시는 다릅니다. RSS 감시는 이미 발생한 순간적 초과를 예방하는 하드웨어 제한이 아닙니다.

## 남은 한계

수정은 단순 문서의 핵심 입력 선택과 한 문장 압축을 개선합니다. 복잡한 문서의 인과·부정·시제 오류, 긴 문서 전체의 누락을 모두 해결하지는 못했습니다. 실제 사용자 문서 평가와 실제 RAM 4GB VM/기기 검증은 아직 남아 있습니다. 작은 비교 사례만으로 다른 문서의 모델 순위를 일반화하지 않습니다.
