# 문서 처리 원칙

## 로컬 우선

파일 탐색, 검색, 미리보기와 경량 요약은 모두 내 컴퓨터에서 실행합니다. 파일 내용과 경로를 서버로 보내지 않습니다. 인터넷 연결이나 계정 로그인이 필요하지 않습니다.

## 탐색 성능 우선

파일 탐색과 검색을 가장 먼저 보호합니다. 미리보기는 크기를 제한하고, 문서 파싱은 별도 프로세스로 분리합니다. 파서가 종료되어도 탐색 화면은 계속 사용할 수 있습니다.

## 문서만 요약

확장자만 보고 요약을 허용하지 않습니다. 실제 파일 시그니처와 컨테이너 구조를 확인한 후 파서 검증이 성공해야 요약할 수 있습니다. 텍스트 파일에 코드나 기계 로그가 들어 있으면 요약을 제한합니다.

## 출처와 숫자 보호

요약을 표시하기 전에 파일의 이름, 실제 형식과 전체 경로를 확인할 수 있습니다. 원문의 문장을 그대로 발췌하고 페이지, 문단, 슬라이드 또는 시트 위치를 함께 표시합니다.

## 변경된 파일 처리

요약과 추출 결과는 캐시하지 않습니다. 요약 버튼을 누를 때마다 원문을 새로 읽습니다. 긴 문서를 위한 임시 작업 데이터는 파일을 전환하거나 작업을 취소하거나 앱을 닫으면 삭제합니다. 처리 중 문서가 바뀌면 결과를 폐기합니다.
