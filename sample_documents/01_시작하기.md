# 문서함에 오신 것을 환영합니다

문서함은 내 컴퓨터의 파일을 찾고, 원문을 확인하고, 중요한 내용을 빠르게 살펴보는 로컬 문서 탐색기입니다. 파일은 외부 서버로 전송되지 않습니다.

## 문서 찾아보기

왼쪽의 폴더 열기 버튼으로 원하는 폴더를 선택하세요. 파일을 한 번 클릭하면 오른쪽에 이름, 실제 형식, 경로, 크기, 수정일과 생성일이 먼저 표시됩니다. 폴더는 두 번 클릭하여 열 수 있습니다.

검색창에서는 파일 이름과 전체 경로를 검색할 수 있습니다. 하위 폴더를 선택하면 더 깊은 폴더까지 탐색합니다. 문서·코드 본문을 선택하면 파일 내부의 문구도 찾습니다.

## 출처를 보존하는 요약

문서를 선택하고 경량 요약을 누르면 문서의 각 섹션에서 대표 문장을 선택합니다. 원문 문장을 그대로 인용하므로 숫자, 날짜와 이름을 임의로 바꾸지 않습니다. 긴 문서도 마지막 부분까지 대표 근거를 보존합니다.

소형 CPU 모델을 설치하면 AI 원문 선택 버튼으로 중요한 원문 문장 하나를 고릅니다. 모델은 문장 번호만 출력하고, 앱은 해당 원문을 그대로 표시합니다. 숫자·부정·시제를 모델이 바꿔 쓴 문장은 표시하지 않습니다. 섹션별 원문 근거는 별도로 확인합니다. 결과는 캐시하지 않고 매번 원문을 새로 처리합니다.

처리 중인 초벌 요약과 완료된 결과는 구분되어 표시됩니다. 다른 파일을 선택하거나 Escape 키를 누르면 진행 중인 문서 작업을 중단합니다.

## 지원 범위

PDF, DOCX, PPTX, XLSX, HWPX, ODT, ODP, ODS, 자연어 TXT와 Markdown을 지원합니다. PDF를 처리하려면 PyMuPDF가 필요합니다. 스캔 PDF에는 텍스트가 없어 별도 OCR이 필요합니다.

구형 DOC, PPT, XLS, HWP와 RTF는 형식과 메타데이터를 확인할 수 있지만 요약은 제공하지 않습니다. 소스코드, 실행 파일, 압축 파일, 이미지와 설정 파일도 요약 대상에서 제외합니다.
